# Console

The Console panel shows what the attached app prints and throws, lets you
expand objects, and evaluates JavaScript inside the app.

## Quick path

1. Attach to an app in **Targets**.
2. Open **Console**. React Native replays the lines it buffered before you attached, then streams new ones.
3. Type an expression in the bar at the bottom and press Enter.

## What is captured

| Source                                                                             | Protocol event                     | Shown as                                                         |
| ---------------------------------------------------------------------------------- | ---------------------------------- | ---------------------------------------------------------------- |
| `console.log`, `info`, `warn`, `error`, `debug`, `trace`, `assert`, `table`, `dir` | `Runtime.consoleAPICalled`         | Row with the level glyph, the arguments and the calling location |
| Uncaught errors                                                                    | `Runtime.exceptionThrown`          | Red row with the error message and collapsible stack frames      |
| Engine and network messages                                                        | `Log.entryAdded`                   | Row prefixed with the source, for example `[network]`            |
| App reloads                                                                        | `Runtime.executionContextsCleared` | A divider: "JavaScript context was reset"                        |
| Lens itself                                                                        | attach, re-attach, evaluations     | System rows, `›` for commands, `‹` for results                   |

## Filters and controls

- **Level chips** toggle Errors, Warnings, Info, Verbose and System; each shows its count. Verbose is off by default, like Chrome.
- **Filter box** matches the row text, case-insensitive. ⌘F focuses it, Esc clears it.
- **Clear** (⌘L) empties the log on both sides.
- **Preserve log** keeps rows from before a reload. When it is off, a reload clears everything before the divider.
- Lens keeps the last 10,000 rows. When older rows are dropped, a notice says how many.

## Objects

Hermes sends objects as handles without inline previews, so a logged object
reads `Object` until you expand it. Expanding asks the app for the object's
own properties; nested objects expand the same way. After a reload (or a
re-attach) earlier handles are gone, and expanding them shows "no longer
available" instead of a request that would fail.

## Evaluate

The bar at the bottom runs the expression in the app's main context with
`Runtime.evaluate`: command line API helpers such as `$_` are available,
promises are awaited, and thrown errors appear as exception rows. ↑ and ↓
walk the last 100 expressions. The bar is disabled until an app is attached.

## Limits

- Previews are not generated by Hermes; expand to see contents.
- Console groups render as flat rows for now.
- Source maps are not applied yet; locations point at the bundle.
