# Milestones

Lens is built milestone by milestone. Each milestone has a tracker pull
request on GitHub and a note here with its objective, scope and acceptance
checks, so contributors can see what is in flight and what is done.

| #   | Milestone                      | Outcome                                                       | Status    |
| --- | ------------------------------ | ------------------------------------------------------------- | --------- |
| M0  | [Foundation](m0-foundation.md) | Repository, desktop shell, design system, CI                  | In review |
| M1  | [Connect](m1-connect.md)       | Discover apps from Metro, attach, metadata, reload, reconnect | In review |
| M2  | Console                        | Logs, errors, object trees, eval                              | Planned   |
| M3  | SDK + Queries                  | `@rnlens/sdk`, TanStack Query and Mutations panels            | Planned   |
| M4  | Network                        | Requests, bodies, timing, cURL, HAR                           | Planned   |
| M5  | Storage                        | AsyncStorage, MMKV, SecureStore                               | Planned   |
| M6  | Performance                    | Traces, profiles, screenshots                                 | Planned   |
| M7  | Plugins and distribution       | Plugin API, docs site, releases                               | Planned   |
